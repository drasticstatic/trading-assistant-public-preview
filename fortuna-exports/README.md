# fortuna-exports/ — Trading Journal (Current)

This is the active home for everything Fortuna generates going forward — pre-market prep, individual trade reviews, and daily/weekly/monthly overview summaries. It supersedes `smarttrader-ai/` as the place new content lands.

`smarttrader-ai/` isn't going anywhere — it stays in the repo as the original build and a showcase of how this system started (Feb–Aug 2026, tied closely to the SmartTradingBlueprint/SmartTraderAI coaching platform). See `smarttrader-ai/README.md` for the transition note. This directory is the fork: same journaling discipline, a name and structure that isn't tied to one coaching program, since Christopher's journaling now spans multiple coaching relationships (STB, ZTH, IT) rather than one.

## 📂 Subdirectories

| Directory | Contents |
|-----------|----------|
| [`premarket-analysis/`](premarket-analysis/) | Pre-session prep — bias, levels, news, expectations (replaces `smarttrader-ai/analysis/premarket/`) |
| [`trade-reviews/`](trade-reviews/) | Individual trade reviews — one file per trade (replaces `smarttrader-ai/reviews/`) |
| [`overview-summaries/`](overview-summaries/) | Daily, weekly, and monthly review exports (replaces `smarttrader-ai/exports/`) |

> **Status (Aug 2026):** all three subdirectories are currently empty — content lands here as the `_csv-2B-filed`/`_Screenshots-2B-filed` backlog is processed into trade reviews. See each subdirectory's README for the structure that will populate.

## 📄 What Lives at This Level

Content that doesn't fit the three categories above — cross-cutting audits, quarterly reviews, or anything spanning multiple categories — lives directly in `fortuna-exports/`, not nested under a subdirectory.

## 📄 File Naming Conventions

Same suffix/date conventions as the original `smarttrader-ai/` structure — see each subdirectory's README for specifics.

## 📊 Pattern Tracker

The active behavioral pattern log lives at [`data/progression/pattern_tracker.md`](../data/progression/pattern_tracker.md) — moved there so it sits alongside the rest of Christopher's progression record rather than under one export directory.
