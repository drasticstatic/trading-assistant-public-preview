# premarket-analysis/ — Pre-Market Summaries

Daily pre-market summaries generated by Fortuna before each trading session. Covers HTF bias, key levels, news events, and intraday expectations.

Replaces `smarttrader-ai/analysis/premarket/` for new content — see [`fortuna-exports/README.md`](../README.md) for the transition note.

## 📂 Structure

Files are organized by year and month:
```
premarket-analysis/
└── YYYY/
    └── MM-Mon/
        ├── premarket_YYYYMMDD_summary.md   ← main summary
        └── premarket_YYYYMMDD_[instrument].md  ← per-instrument (CL, SOL, etc.)
```

## 📋 Pre-Market Sections

Each summary covers:
- `📋 Dashboard` — account status, active trades
- `⚠️ Risk Alert` — prop firm constraints, drawdown proximity
- `🌙 Overnight/ETH` — overnight price action
- `🌤️ At the Open` — HTF bias and key levels
- `🔗 SMT Scenarios` — triple-index divergence reads
- `📅 Calendar` — news events, EIA windows
- `🎯 Priority Instruments` — what to focus on
- `🧠 Mental State` — pre-session self-check
- `⏱️ Live Updates` — brief session notes
- `🤖 Copy-Paste` — coaching-platform copy-paste format
