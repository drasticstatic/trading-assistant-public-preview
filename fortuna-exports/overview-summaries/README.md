```
overview-summaries/
└── YYYY/
    └── MM-Mon/
        ├── export_YYYYMMDD_daily-review.md
        ├── export_YYYYMMDD_weekly-review.md
        └── export_YYYYMMM_monthly-review.md
```

## 📋 Export Formats

### Daily Post-Market Review (3 Questions)
- Q1: What happened today?
- Q2: What did I learn?
- Q3: Results — P/L, rule adherence, grade

### Weekly Check-in (9 Questions + Action Steps)
- What worked / didn't work
- Observable patterns
- Mistakes + solutions
- Yes/No performance questions
- Action steps for the coming week
- Study plan

### Monthly Review
- Full month arc, aggregate P&L, pattern trend analysis across the month's weekly/daily reviews
