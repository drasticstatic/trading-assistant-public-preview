# trade-reviews/ — Individual Trade Reviews

One file per trade, generated by Fortuna after each session. Covers trade data, behavioral analysis, pattern tracking, and notes for coaches.

Replaces `smarttrader-ai/reviews/` for new content — see [`fortuna-exports/README.md`](../README.md) for the transition note. The active pattern log now lives at [`data/progression/pattern_tracker.md`](../../data/progression/pattern_tracker.md), not nested under this directory.

## 📂 Structure

```
trade-reviews/
└── YYYY/
    └── MM-Mon/
        └── review_YYYYMMDD_[instrument]-[platform]_NNN.md
```

*NNN = day-sequential number, resets each date (001, 002, 003...)*

## 📋 Review Sections (Standard)

1. ⚡ What Happened
2. 📊 Trade Data (table from CSV)
3. 🧠 Behavioral Notes
4. 📝 Notes for Coaches
5. 🔁 Pattern Tracker
6. 📋 Order Execution
7. 📸 Screenshot Timeline (full-size embeds)
