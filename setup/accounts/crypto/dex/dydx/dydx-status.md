# dYdX — Status

> Full regulatory analysis (DeFi DEX section): [../../cex/us-crypto-derivatives-regulatory-landscape.md](../../cex/us-crypto-derivatives-regulatory-landscape.md)

**Account held:** No — not used, reference venue.
**Regulatory status:** Front-end website geoblocked for US IPs. The underlying protocol is public blockchain code and can't itself block a wallet-signed transaction — technically bypassable via direct RPC-node connection, but that forfeits any exchange-side safety net.
**What's tradeable:** Perpetual futures, on-chain.
**Key facts:** Direct-RPC access carries real oracle-manipulation/exploit risk with zero customer support or regulatory recourse if something goes wrong — not treated as a practical option given the existing CFTC-compliant alternatives (Coinbase Advanced, Kraken Pro).
