# Kraken Pro (Kraken Derivatives US) — Status

> Full regulatory analysis: [us-crypto-derivatives-regulatory-landscape.md](../us-crypto-derivatives-regulatory-landscape.md)

**Account held:** No — not currently held, reference venue.
**Regulatory status:** Fully CFTC-compliant, one of only a few domestic options. Kraken's parent (Payward) acquired Bitnomial Exchange, LLC (a CFTC-regulated DCM); perps are offered via NinjaTrader Clearing, LLC (d/b/a Kraken Derivatives US), a registered FCM.
**What's tradeable:** Perps integrated directly into the main Kraken Pro dashboard alongside spot/margin.
**Key facts:** Requires a Futures Eligibility Check plus full KYC before the Perps tab unlocks; some US states carry additional local restrictions on top of the federal framework. Worth evaluating alongside Coinbase Advanced as a compliant path if BTCC access ever becomes untenable.
