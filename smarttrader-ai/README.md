# smarttrader-ai/ — Session Reviews & Coaching Exports (Legacy Showcase)

This directory holds all session analysis, trade reviews, pre-market summaries, and SmartTraderAI coaching exports generated by Fortuna (Claude Code CLI) from Feb through early Jun 2026.

> **📣 Transition notice (Jun 2026):** This directory is no longer where new content lands — it stays in the repo as-is, a showcase of how the trading-assistant system started. New premarket analysis, trade reviews, and daily/weekly/monthly overview summaries now go to [`fortuna-exports/`](../fortuna-exports/README.md).
>
> Why the fork instead of a rename: `smarttrader-ai` is a general enough term, but it's also literally SmartTradingBlueprint's coaching-AI platform name — and journaling here has grown to span multiple coaching relationships (STB, ZTH, IT), not just one. Splitting the concerns keeps this directory an honest historical record while giving ongoing journaling a name that isn't tied to a single program.
>
> Nothing here was moved except `pattern_tracker.md`, which now lives at [`data/progression/pattern_tracker.md`](../data/progression/pattern_tracker.md) so the active pattern log sits alongside the rest of Christopher's progression record — a redirect stub remains at the old path. Every other file (reviews, exports, premarket analysis) stays exactly where it is; historical/coach-shared links are untouched.

## 📂 Subdirectories

| Directory | Contents |
|-----------|----------|
| `analysis/premarket/` | Pre-market summaries — bias, levels, news, expectations |
| `reviews/` | Individual trade reviews — one file per trade, date-sequential numbering |
| `exports/` | SmartTraderAI copy-paste exports (daily + weekly formats) |

## 📄 File Naming Conventions

| File Type | Pattern | Example |
|-----------|---------|---------|
| Pre-market summary | `premarket_YYYYMMDD_summary.md` | `premarket_20260325_summary.md` |
| Per-instrument pre-market | `premarket_YYYYMMDD_[instrument].md` | `premarket_20260325_CL.md` |
| Trade review | `review_YYYYMMDD_[instrument]_NNN.md` | `review_20260316_RTY_002.md` |
| Daily STB export | `STB_export_YYYYMMDD_daily-review.md` | `STB_export_20260316_daily-review.md` |
| Weekly STB export | `STB_export_YYYYMMDD_weekly-review.md` | `STB_export_20260322_weekly-review.md` |

*NNN = day-sequential number (resets each date, not global)*
