# trades_2026_02-09-thru-04-27.csv

TradeZella CSV export covering **Feb 9 – Apr 27, 2026** — the early Apex/TPT eval-reset stretch
(Apex-484839-01 through -06, TPT 635000920 through its reset chain to 558167553). Sits directly
under `2026/` rather than a `MM-Mon/` subfolder because it spans multiple months as one export,
not a single-month pull.

## Why it's here

TradeZella computes fields Tradovate's own order-fill CSVs don't carry — most usefully the
**Zella Score** column, plus Exit Efficiency, Confluence, Mistakes, and other trade-quality
fields TradeZella derives automatically. The Tradovate order-fill exports (`tradovate_orders_*.csv`
elsewhere in this tree) remain the authoritative source for fill prices, quantities, and realized
P&L — this file is a cross-reference layer for trade-quality scoring, not a primary fills source.

## Coverage caveat

TradeZella computes P&L off its own cost-basis math, which doesn't always account for broker
commission the way the Tradovate-sourced ledger does — treat this file's `Net P&L`/`Gross P&L`
columns as directional, not authoritative. `Zella Score` and the qualitative fields are the reason
to keep this file around.
